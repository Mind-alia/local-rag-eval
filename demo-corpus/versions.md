# Journal des versions

## 1.2.0

- Nouvelle option `--exclure`, répétable, pour ignorer des fichiers par motif.
- Le niveau de compression par défaut passe de 6 à 3.

## 1.1.0

- Les extensions peuvent être déclarées dans le fichier de configuration.
- `cagibi scan` affiche la taille de chaque fichier.

## 1.0.0

- Première version stable, avec `scan`, `range` et `restaure`.

## 0.9.0

- Version d'essai, sans extensions.
