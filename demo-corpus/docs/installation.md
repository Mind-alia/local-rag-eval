# Installation

cagibi est livré sous la forme d'un seul exécutable, sans dépendance.

## Installer

1. Télécharger la dernière version sur la page des versions du projet.
2. Placer l'exécutable `cagibi` dans un dossier du `PATH`.
3. Vérifier l'installation avec `cagibi --version`, qui affiche le numéro de version.

## Mettre à jour

`cagibi mise-a-jour` remplace l'exécutable par la dernière version publiée. Les archives déjà
créées restent lisibles : leur format ne change pas d'une version à l'autre.

## Désinstaller

Supprimer l'exécutable, puis le dossier `~/.cagibi/`. Les archives déjà créées ne sont pas
touchées.
