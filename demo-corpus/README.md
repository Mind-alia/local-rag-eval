# Demo corpus, invented for the example

Everything in this folder is fiction. **cagibi** is a command-line tool that does not exist: these
seven short pages were written for this repository so that the bench can run end to end on public
data. Any resemblance to a real tool is accidental.

The pages are in French because the bench's prompt is French. [`../corpus.txt`](../corpus.txt)
lists them and [`../questions.json`](../questions.json) asks 10 questions about them. This README
is not part of the corpus.

*Corpus de démonstration inventé pour l'exemple : cagibi n'existe pas.*
